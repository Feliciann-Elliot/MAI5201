## Citation
Pang, B., Lee, L., & Vaithyanathan, S. (2002). Thumbs up? Sentiment classification using machine learning techniques. *Proceedings of the ACL-02 Conference on Empirical Methods in Natural Language Processing*, 79-86.

## Summary
This paper addresses sentimental classification using the test case of determining whether movie reviews were positive or negative. This type of analysis required and understanding of subtle language cues unlike topic-based text categorization because sentiment is frequently implied instead of being stated explicitly.

Using a movies review dataset, the authors did a comparative analysis of three machine-learning algorithms vs. human generated baselines. The algorithms were (Naive Bayes, Maximum Entropy, and Support Vector Machines (SVMs)). It was found that the three algorithms outperformed the human by a huge margin; especially the SVM which achieved the highest overall accuracy.

The authors tested simple word-list approaches created by humans to establish baselines. And these methods performed with accuracy from 58% to 69% and resulted in frequent ties. This indicates that there was a lot of ambiguity in sentiment analysis. On the other hand, the machine learning models that were trained on labeled data performed better. However, the ML performance was still below topic classification benchmarks

The paper also speaks about feature selections and representation, indicating that bigrams and some punctuation marks such as question marks can be very informative. It further emphasizes that sentiment classification is more nuanced than keywork spotting and therefore requires further research in order to improve performance.

Overall, the paper shows that it is feasible to use ML for sentiment analysis and sets a precedent for future advancements in opinion mining and nural language understanding. It also highlights how important it is to have tailored approaches in text classification tasks.
